A single 1024×1024 front page for Thursday 26 November 2026. Thirty-eight stories, all verified against same-day reporting: the Houthi claim on Ras Tanura and the postponed 100th Macy's parade lead the page; six drawn cards cover Hormuz, Gaza, Samara, Mumbai's 26/11 anniversary, BepiColombo at Mercury and the Cairo tanker fire; a UTC timeline, a schematic pin map and a thirty-item index fill out the day. The picture is drawn in code (PIL) during the build — no photographs, no copied art.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` checks the picture against the contest caps (whole PNG, at most 1 MiB, at most 1024×1024) and copies it to the output directory. It writes identical bytes on every run.
